
Целью данного курсового проекта является разработка функционального веб‑сайта «Планировщик привычек», реализующего удобный пользовательский интерфейс и основные механики работы с привычками — создание и редактирование записей, отметки выполнения и визуализация прогресса — с применением современных веб‑технологий. Для достижения поставленной цели необходимо решить следующие задачи:
•	разработка макета и структуры пользовательского интерфейса с учётом пользовательских сценариев (создание/редактирование привычек, отметки выполнения, просмотр прогресса)
•	создание семантической структуры HTML для корректного представления контента и обеспечения доступности
•	стилизация интерфейса с помощью CSS, включая адаптивный дизайн и оформление элементов управления и графика прогресса;
•	внедрение интерактивности с помощью JavaScript: обработка событий, логика создания/редактирования привычек, отметки выполнения, обновление данных в реальном времени и построение графика прогресса 
•	обеспечение хранения состояния (локальное хранилище или API) и валидации пользовательского ввода для надёжной работы приложения
